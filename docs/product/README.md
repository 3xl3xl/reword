# RE:WORD

> この文書は会話から整理した要求・仕様のスナップショットです。「未確認」は会話から確認できなかったことを示し、未実装という意味ではありません。現行サービスの起動方法・API・永続化・クイズの実装仕様は[リポジトリのREADME](../../README.md)とソースコードを参照してください。

会話で出会った英語を保存し、短い復習と英文づくりで「知っている」から「使える」へつなげる個人向け英語学習プロダクト。

RE:WORDは、保存した単語・フレーズのクイズと、ブロックを並べて英文を作る **Sentence Blocks** を中心に構成します。自分の生活に近い題材で、既知の単語から100〜200個の基本文を自在に作れるようになることを目指します。

## 主な体験

| 機能               | 内容                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| 単語・フレーズ保存 | `scatter save it` などの自然な指示で保存。意味・類語・例文を返す形式が会話に登場 |
| 保存語彙の復習     | 意味から英語を思い出す問題などを1問ずつ提示。回答後に短く解説                    |
| 朝夜クイズ         | 毎日08:00と22:00、Asia/Tokyo。接続済みRE:WORDの実際の状態を確認して開始・再開    |
| Sentence Blocks    | 日本語に対応する英文をブロックで構成。5問を連続して解く                          |
| タップとドラッグ   | タップで追加・取り消し。回答欄のブロックをドラッグして並べ替え                   |
| 音声と効果音       | 選択した英語を男性音声で読み上げ、正解時は完成文を読み上げ。選択・正誤の効果音   |
| Personal / Hard    | 個人的な題材と、接続詞を使った長めの文。独立したモード切替UIは未確認             |

## 学習の流れ

1. 会話で出会った単語やフレーズを保存する。
2. 手動または朝夜のクイズで、1問ずつ思い出す。
3. Sentence Blocksで語順と文の構造を練習する。
4. 選択語と完成文の音声を聞いて、英文に慣れる。
5. 将来的に自力入力・発話・自分の文への応用へ広げる。

5は会話で提案された学習の方向性であり、実装済み機能ではありません。

## UI / UXの要点

- 選択肢を使っても元の位置を詰めず、同じサイズの文字なし・非アクティブなブロックを残す。
- 回答カードは複数行になってもサイズが揃うようにする。具体的な寸法は未決定。
- ドラッグ中は挿入位置に滑らかな空間を作り、どのブロックの間に入るかを示す。
- 挿入判定は細かすぎない、広めの操作領域にする。
- 正解後は **Next** を単独で横幅いっぱいに表示する。
- 音のON/OFF操作を右上に配置する。読み上げとの連動範囲は要確認。

## 定時実行の原則

スケジュール名は **RE:WORD 朝夜クイズ**。同名があれば更新し、重複を作らない方針です。

開始時は `start_quiz`、回答時は `get_quiz` で最新状態を確認してから `answer_quiz` を使用します。未完了なら再開し、`current.prompt` を1問だけ提示して回答を待ちます。正解の先出しや回答の捏造は行いません。

対象なし・同じ時間帯の完了済み・接続失敗を明示し、実行結果はChatGPTプッシュ通知で知らせる要求です。会話には作成報告がありますが、現時点の有効状態や通知到達は未検証です。
